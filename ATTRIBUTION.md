# Attribution

Every asset DiaCraft includes, bundles, embeds at build time or shows in its documentation, with its author, source and
licence. The policy is in [`AGENTS.md`](AGENTS.md). `cargo xtask assets` fails if an asset file is missing from this table: any
file under `assets/` or `docs/images/`, and any file elsewhere with an image, icon, font, colour-profile, audio, video,
PDF, VSDX-family, CAD or metafile extension (the list is `ASSET_EXT` in `xtask/src/assets.rs`).

DiaCraft contains no Microsoft, Adobe, Avid or Autodesk iconography, images, fonts, themes, templates or stencils.

A typeface that a dependency compiles into a build is no file of this repository, and `cargo xtask assets` has no file to ask a
row for. It has a row all the same: the first cell names the crate and, after it, the file inside the crate, and the last cell
names the builds that carry it. Both builds run the same window (`crates/ui-egui`), so both carry its two typefaces.
