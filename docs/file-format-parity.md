# File format parity

> **Last reviewed:** 2026-10-31

Every format in scope, with DiaCraft's support, fidelity and tests. No file the reference app made is committed or used as a fixture. The target is the reference app's desktop edition, and M1 sets which release. The reference app was not inspected, nothing was launched or measured, and our output has not been opened in it by the project.

**Headline:** DiaCraft opens and saves Visio drawings, stencils and templates (`.vsdx`, `.vsdm`, `.vssx`, `.vssm`, `.vstx`, `.vstm`), OpenDocument drawings and templates (`.odg`, `.otg`, `.fodg`) and its own `.diacraft` files.
The six VSDX types are read into the model and written back, OpenDocument drawings (`.odg`, `.fodg`) are read and written in their own format, and a page exports as PNG, SVG and PDF; the engine also opens and saves DiaCraft's own `.diacraft`, which the window's file dialogs offer first; a drawing is saved across the VSDX and OpenDocument formats by the model writer of the target; no other format is supported. It is measured by tests built in code and, for the formulas, by public sample files. `.diacraft` is the format of a new drawing (0.2, [`roadmap.md`](roadmap.md)), and a file that was opened is saved in its own format.
