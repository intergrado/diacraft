**How to read it.** A dotted word such as `shape.drop` is an engine command ([`editing-commands.md`](editing-commands.md)); a word such as `view.grid`, `format.text` or `arrange.align` is a command of the window, which the control channel reaches as it reaches the engine's. A path such as `edit/gesture.rs` is under `crates/ui-egui/src/` unless it starts with `draw/`, which is under `crates/engine/src/`.
