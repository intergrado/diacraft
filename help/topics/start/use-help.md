Help is a set of short topics. Each one is about a single task, and each says what DiaCraft does and what it does not do yet.

## Find a topic {#find}

The help home lists the topics in sections. Choose a section's topic to read it. To look for a word instead, search the help: the topics whose title, headings, keywords, summary or text hold your words come back with the best match first.

## Follow a link {#links}

A link in a topic is one of four kinds:

- a link to another topic, or to a place in a topic, goes there;
- a link to a control or a command shows its name and its key as they are in your window, so the topic stays right when a key changes. A click shows where the control is. It never runs the command;
- a key is written the way your system writes it: the main modifier is Command on a Mac and Ctrl on Windows and Linux;
- a link to the website, the web app or the public repository opens your browser.

## Move back and forth {#history}

Help remembers the places you have been. Back and Forward walk through them, and Home returns to the help home. The key [Alt+Left](key:Alt+Left) goes to the help home.

> Every topic works with no network connection. Only a link to the website needs one.

The [Help](ctl:Help) button on the Help tab opens help at its home.
