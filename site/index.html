Free, open-source diagram editor

Open, edit and convert Visio and OpenDocument drawings.

Bring the files you already have. DiaCraft saves each drawing back as the type it came in, or converts it to another, in the window or from the command line. OpenDocument is the format of LibreOffice Draw and OpenOffice.

Formats

One drawing, three files.

Save keeps a drawing in the format it arrived in. Save As writes it as another type, and diacraft-cli convert does the same from a terminal.

Open & save
Visio drawings, stencils and templates (.vsdx, .vsdm, .vssx, .vssm, .vstx, .vstm), OpenDocument (.odg, .otg), and native .diacraft files.
Convert
Save a drawing of one family as a type of another. Where the new type cannot hold part of a drawing, the save tells you what, in words.
Export a page
Choose PNG for a raster image, SVG for scalable artwork, or PDF for sharing.
Print
Preview the sheets, choose the pages you need, then send the drawing to your system printer.

The older binary and XML drawing types (.vsd, .vdx) are not supported.

The editor

Inside the editor

A flowchart on a sheet whose frame and title block belong to a background page. The numbers mark what the notes below describe.

  1. 1Start with a stencil

    Drag shapes from seven built-in stencils, including Basic Flowchart and Gane-Sarson. Open a stencil file to add your own choices.

  2. 2Route a connector

    Use AutoConnect to join a neighbour. Drag a handle on a right-angle connector to move a leg around a label.

  3. 3Change the colour scheme

    Choose a theme from the Design tab, then try its variants to change the colours across a page.

  4. 4Reuse a background

    Give a background page a title block or frame. Assign it to the pages that need it and edit it in one place.

  • Draw a custom shape

    Draw rectangles, ellipses and arcs, or sketch a freeform path and close it to make a filled shape.

  • Runs in your browser

    Nothing to install: a current desktop browser runs the editor in a tab and keeps your drawing on your computer.

Automation

Automate drawing tasks.

Convert files from the command line or connect an AI agent through the MCP server to inspect and edit a drawing.

From the command line

Write an editable drawing with convert, or a picture of one page with export. Both work without opening a window, and each prints a line of JSON that says what it wrote.

Command-line guide

With an AI agent

An agent can create a diagram in its own session or edit the drawing you see on screen. It finds the drawing commands with command_list and runs them with command_run.

Privacy

Your drawings stay on your desk.

  • No account
  • No telemetry
  • Offline draw, save, export

Draw, save and export offline. DiaCraft needs no account and collects no telemetry. If a file is damaged or exceeds a reader’s safety limits, the app explains why it cannot open it.

The optional control port listens on your own computer. An MCP client can use a connection you specify. Your print service handles printer jobs, and licence links open in your browser.

FAQ

Questions

What should I save a new drawing as?

Use the default .diacraft format to keep an editable drawing. When you open an existing .vsdx or .odg, Save writes back to that format. Explore the native format.

Can I export just one page?

Yes. Export a page from the window, or choose it by number with diacraft-cli export. See command-line examples.

Can I try DiaCraft without installing it?

Yes. Open DiaCraft in your browser to draw in a tab. It opens and saves .diacraft, .vsdx and .odg files on your computer and exports PNG, SVG and PDF, and it sends nothing anywhere. Very large drawings, your own fonts and printing are for the desktop app. What the browser version needs and what it keeps

Does DiaCraft run macros in a drawing?

No. A macro-enabled package can carry its macro project when saved in a macro-enabled type. DiaCraft never executes that project.

Help shape DiaCraft.

If a connector takes an unexpected turn or a drawing opens differently than you expected, open an issue. Include the file type, your platform and the steps that led to the result.

Browse the source to contribute a fix. The code is available under your choice of the MIT or Apache 2.0 licence. Credits are in NOTICE, and the licences of the libraries DiaCraft is built from are in THIRD-PARTY-LICENSES.txt, which every download carries too.
