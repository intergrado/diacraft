How to read this page

Each area has its own table, and each row of it is a group of related features, such as selecting shapes or routing connectors. A cell says how much of the group a tool has, as far as its public documentation shows. Open a cell’s note or sources to see what was found, the pages it rests on and the day they were read. Open DiaCraft’s cell of a row to see the row’s id, which a correction can name.

Full
All of the group is there.

As of 31 October 2026 and 26 November 2026. Every cell comes from public documentation or, for some of LibreOffice Draw's, from a copy of it run as a black box: the pages of Visio were read on 31 October 2026, and those of draw.io and LibreOffice Draw on 26 November 2026. The DiaCraft column is computed from its parity checklist, whose scores were last reviewed on 22 November 2026, for release 0.2.4. Report a correction on GitHub with the row, the cell and a public source.

Where each column comes from

  • Visio. The rows are the features of its desktop edition, taken from the vendor’s public support pages, so this column is Full unless those pages or the vendor’s comparison of its plans say otherwise. A caption names the plans when only some have a feature. No cell of this column is a measurement of Visio. In its notes, “the vendor” is the company that sells it.
    • Plans 1 and 2: the vendor's plan comparison puts the feature in Plan 1 and in Plan 2.
    • Desktop plan: the comparison puts the feature in the plan that includes the desktop app, and not in the two web plans.
    • Varies by plan: parts of the feature are in different plans, and the note says which.
    • Web app: the feature is the web app's, or an online service's.
  • draw.io and LibreOffice Draw. Read from each tool’s own public documentation. A cell is Full only if the pages show every part of the row, and Partial if they show some of it; the note says which parts were found and which were not. LibreOffice’s file filters, Gallery themes and shape handles were also read from a copy of it run as a black box.
  • DiaCraft. Computed from the project’s parity checklist at every release: Full if every checklist row of the group is done, Not yet if every one is missing, and Partial otherwise. Scores err low. The few rows that name no checklist row, the file formats and the platforms, are read from the file format and platform documents.
