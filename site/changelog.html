New drawings start in .diacraft

The first time you save a new drawing, the desktop app offers .diacraft first. The file holds the drawing’s pages, shapes and styles, including details imported from VSDX and OpenDocument packages. Opening an existing .vsdx or .odg and choosing Save keeps its file type.

Grid, ruler, guide and connection-point visibility now travel with the drawing. Save after changing one of these settings to see it again when you reopen the file.

More ways to exchange an editable drawing

  • Save a native drawing as a VSDX drawing, an OpenDocument drawing (.odg) or an OpenDocument template (.otg).
  • Save a VSDX drawing as an OpenDocument drawing, or an OpenDocument drawing as a VSDX type.
  • Start an untitled drawing from an .otg template. Your first save gives the drawing its own filename.
  • Check a conversion with diacraft-cli roundtrip and --via diacraft. For a VSDX or ODG package, the report compares the original content with the copy written back to the source format.

Testing a wider range of files remains part of the release work. Read the current format limits.
