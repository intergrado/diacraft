DiaCraft/Visio files

A free Visio alternative for Linux, Mac and Windows.

DiaCraft is a free, open-source diagram editor. It opens Visio drawings, stencils and templates, lets you change them, and saves each one back as the type it came in. It runs on Linux, macOS and Windows, and in a browser tab.

DiaCraft 0.2 is an early release. You can draw, format and connect shapes and save the result, but many controls of the window are shown and do not work yet, and the older .vsd and .vdx files do not open.

Open .vsdx files without Visio

Choose File → Open (Ctrl+O) and pick a drawing. DiaCraft reads Visio drawings, stencils and templates (.vsdx, .vsdm, .vssx, .vssm, .vstx and .vstm) and draws every page of the drawing. Make your changes, then choose Save: the file is written back as the same type.

  • Drawings (.vsdx, .vsdm) open for editing.
  • Templates (.vstx, .vstm) start a new, untitled drawing.
  • Stencils (.vssx, .vssm) open from the Shapes window, under More Shapes → Open Stencil, so you can drag their shapes onto the page.
  • Macros in a .vsdm, .vssm or .vstm are kept in the file and never run.

The files DiaCraft writes are being tested by opening them in Visio, LibreOffice Draw and draw.io. If one does not open as you expect, an issue that says what happened helps.

If part of a page cannot be shown, or is drawn approximately, a mark in the status bar says so, and a click on it lists what, in plain words. Read the file format guide

Visio files on Linux and Mac

DiaCraft is a desktop app for Linux, macOS and Windows, and each download holds the app and its command line tool.

  • Linux: an AppImage, a .deb for Debian and Ubuntu, a .rpm for Fedora, or a .tar.gz, for Intel/AMD and ARM64, on a desktop with glibc 2.35 or newer.
  • macOS: macOS 11 or newer, with a build for Apple silicon and one for Intel Macs.
  • Windows: Windows 10 or 11, on Intel/AMD or ARM64, with an installer that needs no administrator rights.

The downloads are not signed yet, so macOS asks you to confirm the first time you open DiaCraft, and Windows may ask too. Go to the downloads

Open .vsdx online, in a browser

The same editor runs in a browser tab at diacraft.app, with nothing to install. Open a .vsdx file with File → Open, or drop it on the page. The file is read in the tab on your computer and is not uploaded anywhere. Save it as .vsdx, .odg or .diacraft, or export a page as PNG, SVG or PDF.

The browser version opens smaller drawings than the desktop app, has only its two built-in fonts and cannot reach a printer. It has been run in current releases of Chrome and Firefox on Linux. What the browser version needs and what it keeps

Convert .vsdx to PDF, SVG or .odg

To share a page, choose File → Export and pick PNG, SVG or PDF. To hand the drawing to someone who uses LibreOffice Draw, choose File → Save As and pick .odg. Where the new type cannot hold part of the drawing, the save says what, in words.

How DiaCraft compares

If you are choosing a diagram editor for Visio files, these are DiaCraft’s terms:

Opens and savesThe six Visio types, OpenDocument .odg, .otg and .fodg, and .diacraft
ExportsA page as PNG, SVG or PDF, and printing with a preview
OfflineDraw, save and export with no connection and no telemetry
AutomationA command line tool, and an MCP server for AI agents

DiaCraft’s own format, .diacraft, has a public specification, and a drawing saved in it keeps the details that came from a VSDX or OpenDocument file. Work with .diacraft files

What does not work yet

  • Older files. The binary and XML drawing types from before VSDX (.vsd, .vss, .vst, .vdx, .vsx, .vtx) do not open.
  • An early release. Many controls of the window are shown but do not work yet.
