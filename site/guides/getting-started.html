Draw your first diagram

Make a two-step review process. You’ll give each step a label, join the steps, then move one to see how the connector follows.

Start with two shapes

Open DiaCraft and choose File → New → Blank drawing. If you are working from a configured source checkout, you can launch the desktop app from the repository directory with cargo run --release -p diacraft.

  1. In the Shapes window, choose Basic Shapes. Drag a rectangle onto the left of the page and a second rectangle onto the right. Leave a little space between them.
  2. Double-click the first rectangle and type Draft. Click the page to finish editing. Label the other rectangle Review the same way.
  3. On the Home tab, choose the Connector tool. Drag from Draft to Review. Press Esc to return to the Pointer Tool, then drag Review lower on the page. The connector should stay attached at both ends.

Save a drawing and share a copy

Choose File → Save and name the drawing review.diacraft. Open it again with File → Open to continue editing the shapes and their connection.

To put the diagram in a report, use File → Export and choose PNG, SVG or PDF. To see how the drawing fits on paper, open File → Print and check the sheet preview.
