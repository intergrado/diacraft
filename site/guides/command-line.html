Convert drawings from the command line

Use diacraft-cli convert to write an editable drawing, or diacraft-cli export to make a picture of one page. Both work without opening a window.

Make an editable copy

With diacraft-cli on your path, open a terminal in the directory containing your drawing. These examples use a file named review.vsdx. The destination extension selects the format, and the output path must differ from the input.

The first command makes a native working copy. The second reads that copy and writes an OpenDocument drawing. Check the result after each command. A drawing conversion uses the same format rules as Save As in the window.

Export a page for sharing

Page numbers start at 1, and the first page is the default. Use --dpi to control the size of a PNG. Choose an output name ending in .svg or .pdf for vector output.

Read the result

A successful command prints a JSON object. For a conversion, check warning_count and warnings. For an export, skipped lists features that were omitted or approximated. This is what the two conversions above printed for the drawing on the home page.

Exit status 1 means the operation failed. Status 2 means the command line needs correcting. Read standard error for the reason.

StatusWhat it meansStandard error, for example
0The command did what was asked and printed its JSON object.Nothing
1The operation failed.cannot read the drawing: there is no such file
2The command line needs correcting. Nothing ran.--out must end in .png, .svg or .pdf: that says what to write
