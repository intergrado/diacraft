Work with .diacraft files

A new drawing defaults to .diacraft the first time you save. Reopen it to edit its pages, shapes, labels and connections.

Keep an editable working copy

  1. Open a .vsdx or .odg drawing, then choose File → Save As.
  2. Select the DiaCraft drawing type and give it a name such as review.diacraft. Check the window title for the new filename. Further saves go to this working copy.
  3. When someone needs an editable copy in another format, use Save As again and choose one of the types offered for the drawing. Use Export for a picture of a page.

What the file keeps

Each file is a ZIP package. It contains XML for the pages, reusable shapes, styles and connections, along with the drawing’s pictures. A shape cell can store a formula, its last calculated value and its unit. The package can also keep details from imported drawings, such as a VSDX relationship or an OpenDocument style name, without embedding the entire source file.

EntryWhat it holds
mimetypeThe media type of the file
manifest.xmlThe format version, the kind of file, and a row for every other entry
document.xmlThe document: its title, properties, colours, fonts, styles and themes
pages/One part for each page, with its shapes and connections
masters/One part for each reusable shape
blobs/Pictures and other data, each stored once
state.xmlBookkeeping of the program that wrote the file
preview.pngA small picture of the first page, for file managers

The drawing keeps settings such as grid and ruler visibility. Your selection, zoom level and undo history belong to the editing session.

Choose a drawing, stencil or template

  • .diacraft is the drawing you open and edit.
  • .diacraft-stencil holds reusable shapes for the Shapes window.
  • .diacraft-template provides a starting drawing. Open it to begin a new unnamed drawing with its contents.
