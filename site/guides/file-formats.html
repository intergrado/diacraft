Open and save drawing files

Have a drawing to revise? Use File → Open, make your changes, then choose Save to keep using its current format. Templates and flat drawings have different save rules.

Visio drawings, stencils and templates

  • Drawings use .vsdx or .vsdm. Use Save As with a new name if you want a separate working copy.
  • Stencils use .vssx or .vssm. To use their shapes in a drawing, open the stencil from the Shapes window and drag a shape onto the page.
  • Templates use .vstx or .vstm. Opening a template starts an untitled drawing. Its first save asks for a name of its own.

The formats ending in m can carry a macro project. DiaCraft preserves the project as file data and never runs it. If you choose a VSDX type that cannot carry macros, Save As asks whether to leave them out. Cancel to keep the project.

OpenDocument drawings

Open an .odg to edit a packaged drawing. Open an .otg to start a new drawing from a template. If an edit cannot be written to the requested format, DiaCraft explains why and leaves the existing file intact.

A .fodg holds its drawing in a single XML file. Save writes edits back to that file. Save As writes the drawing as another type and leaves the .fodg as it was; no Save As writes a .fodg.

Choose another format

Choose File → Save As and pick a type. Select .diacraft to keep editing in DiaCraft’s native format, or save a VSDX drawing as an OpenDocument drawing and an OpenDocument drawing as a VSDX type. Where the new type cannot hold part of a drawing, the save tells you what, in words. To share a finished page, use File → Export for PNG, SVG or PDF.
