DiaCraft: third-party licences (the web build)
================================================================================

DiaCraft is free software under the MIT License or the Apache License 2.0, at your option
(LICENSE-MIT, LICENSE-APACHE, NOTICE). Its web build, `diacraft-web`, runs in a browser as
WebAssembly and is built from the Rust crates listed below, and from the Rust standard library.
Each crate has its own licence, and the licence asks that its notice and text go with the
program. This file is that notice: it lists every crate the web build is built from, and gives
each licence text once, with the crates that carry it. The two fonts and the pictures DiaCraft
carries are in NOTICE and ATTRIBUTION.md. The desktop programs have a list of their own,
THIRD-PARTY-LICENSES.txt, which every download carries.

This file is made by `cargo xtask licenses` from Cargo.lock and the crates' own files, and
`cargo xtask licenses --check` keeps it in step. Do not edit it by hand.

--------------------------------------------------------------------------------
1. What is in it
--------------------------------------------------------------------------------

  Web                    148 crates (diacraft-web 148), 8 licences, 80 texts

The counts leave out DiaCraft's own 23 crates, which are under DiaCraft's licence. A crate that
offers a choice of licences (MIT OR Apache-2.0) is listed under the one DiaCraft uses it under:
MIT where it is offered, then Apache-2.0. The web build also uses what the browser provides
(WebAssembly, the canvas, WebGL and WebGPU), which is not part of the program.
